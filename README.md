# Puebla Turística 360°

Prototipo móvil de turismo para Puebla. Funciona sin internet una vez instalado.

- **Turista:** idioma, acceso, verificación de identidad, cotizador, resultados de agencias, pago, confirmación y mis cotizaciones.
- **Empresa:** registro, login, cobros, DataTur, perfil, aviso de privacidad y panel de solicitudes.
- Chatbot de preguntas frecuentes, menú de hamburguesa, tema claro y oscuro, seis idiomas (es, en, fr, de, pt, it).

## Contenido

| Ruta | Qué es |
|---|---|
| `index.html` | Versión compilada, un solo archivo. Es la que se publica. |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | Modo sin conexión e instalación como app. |
| `src/` | Código fuente comentado, con `support.js` e imágenes. |
| `documentacion/` | Estructura, índice de búsqueda y despliegue. |

Para entender el código, empieza por `documentacion/ESTRUCTURA.md` y busca las etiquetas `SEC:` del `documentacion/INDICE-DE-BUSQUEDA.md`.
